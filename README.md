# Chef Bubble Kitchen 🍳

Welcome to **Chef Bubble Kitchen**, an authentic Pakistani and fusion recipe website.

## 📁 File Structure
```text
chef-bubble-kitchen/
├── index.html
├── recipes/ (30 detailed recipe HTML files)
├── css/
│   ├── style.css
│   ├── responsive.css
│   ├── recipe.css
│   └── animations.css
├── js/
│   ├── main.js
│   ├── recipes.js
│   ├── search.js
│   ├── filter.js
│   └── favorites.js
├── data/
│   └── recipes.json
├── assets/
├── about.html
├── contact.html
├── categories.html
├── privacy-policy.html
├── terms.html
├── 404.html

├── sitemap.xml
└── README.md
```

## 🚀 Features
- 30 Detailed Step-by-Step HTML Recipe pages
- Interactive Search bar with instant filter by title, ingredient, or keyword
- Category and Difficulty filters (Pakistani, Fast Food, Desserts, Easy, Medium, Hard)
- Bookmarks / Favorites saved locally in browser LocalStorage
- Interactive Checkable Ingredients for real-time cooking mode
- FAQ Accordions, Chef Tips, Nutrition Grids, and Share options for every recipe
- Fully responsive layout optimized for mobile, tablet, and desktop screens
